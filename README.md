## 🙅 Setup

To run JavaScript programs locally, you need Node.js.

Download it at [nodejs.org/en/download](https://nodejs.org/en/download/) and choose the LTS version for your platform (Windows, Linux or Mac).

Verify the installation:

```bash
node -v
npm -v
```

To run any exercise:

```bash
node path/to/exercise.js
```

Clone the repository:

```bash
git clone git@github.com:williamalonso/javascript-exercises.git
```
